# مولّد تقارير المعمل

أداة ويب بسيطة بتولّد ملفات Word لتقارير تحاليل **مرضى وهميين**، علشان تستخدمها كبيانات اختبار لأنظمة المعامل (LIS). كل مريض بيطلع له ملف Word لوحده. النتايج متسقة مع التشخيص، ومتدرجة من يوم ليوم حسب مسار الحالة.

الأداة كلها شغالة جوه المتصفح. مفيش سيرفر، ومفيش بيانات بتطلع من جهازك.

> الأسماء ثابتة "مريض وهمي ١، ٢…" والمستشفى المحوِّل "مستشفى وهمي". الملفات دي بيانات اختبار، ومش سجلات طبية.

## التشغيل

- **على GitHub Pages**: ارفع الفولدر على ريبو، وبعدين من Settings ← Pages اختار الفرع `main` والفولدر `/ (root)`. الصفحة هتشتغل على `https://<username>.github.io/<repo>/`.
- **على جهازك**: افتح `index.html` في أي متصفح حديث. محتاج إنترنت أول مرة بس، علشان يحمّل مكتبة JSZip والخطوط.

## طريقة الاستخدام

1. ضيف مريض، واكتب السن والنوع وتاريخ الدخول والخروج والمستشفى المحوِّل.
2. اختار التشخيص، وممكن تختار أكتر من واحد. التشخيصات متقسمة لمجموعات: Respiratory وCardiac وNeurology وRenal وElectrolytes وBlood وSepsis & infection وEndocrine وGI & liver وViral markers.
3. اختار مسار الحالة: Improving أو Slow improvement أو Stable أو Deteriorating.
4. لو حابب، اختار المضادات الحيوية اللي عايزها تطلع Sensitive في المزارع.
5. دوس **تنزيل Word** للمريض ده لوحده، أو **تنزيل الكل** علشان ينزلك ملف zip فيه ملفات كل المرضى.

زرار **نتايج جديدة** بيدّي المريض رقم ID جديد وأرقام مختلفة. لو مضغطتش عليه، المريض بينزل بنفس النتايج كل مرة.

## محتوى ملف كل مريض

| التحليل | بيتعمل امتى |
|---|---|
| CRP، كلى، أملاح (صوديوم، بوتاسيوم، كالسيوم Total وIonized) | يومي |
| صورة دم كاملة | يومي |
| غازات الدم (ABG) | يومي. مع DKA: كل ١٢ ساعة ومعاها Acetone لحد ما الحالة تتحسن |
| السيولة و D-Dimer | كل ٣ أيام |
| إنزيمات القلب (CK، CK-MB، Troponin I hs) | مرة واحدة. مع MI: كل ٦ ساعات أول ٢٤ ساعة، وبعدها كل ١٢ ساعة لحد ٧٢ ساعة |
| بول كامل، كبد وبنكرياس، HbA1c، غدة درقية، Iron profile، فيروسات (HCV، HBsAg، HIV)، دهون | مرة واحدة يوم الدخول |
| مزارع دم وبول وبلغم مع المضادات الحيوية | مرة واحدة. تاريخ السحب يوم الدخول، والنتيجة بتطلع بعد ٤–٥ أيام |

## إزاي النتايج بتفضل منطقية

- MCV وMCH وMCHC محسوبين من Hb وHCT وRBC. مجموع نسب كرات الدم البيضا 100%، والأعداد المطلقة محسوبة منها.
- الـ pH محسوب من HCO3 وPCO2، والـ SO2 محسوب من PO2. البوتاسيوم والصوديوم والكالسيوم المتأين في غازات الدم متسقين مع صفحة الأملاح.
- المزارع بتطلع من بكتيريا العناية المركزة، زي Klebsiella وAcinetobacter وPseudomonas وMRSA وVRE. المقاومة متسقة مع نوع البكتيريا ومع عيلة كل مضاد، وكل عمود في جدول المضادات (Sensitive وModerate وResistant) فيه مضادين على الأقل.

## الملفات

```
index.html        الصفحة
css/styles.css    التنسيق
js/core.js        نموذج التحاليل ومولّد ملف Word (من غير أي مكتبة)
js/app.js         الواجهة والتنزيل
tests/run-tests.js  اختبارات الاتساق: node tests/run-tests.js
```

## التطوير

- علشان تضيف تشخيص جديد، ضيفه في `DXG` جوه `js/core.js` مع تأثيره على التحاليل (مثلاً `{ inf: 1, pulm: 1 }`).
- بعد أي تعديل، شغّل `node tests/run-tests.js` علشان تتأكد إن الأرقام لسه متسقة.
